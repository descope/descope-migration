**2. `get_frontegg_access_token()` -- per D-07:**
- POST to `https://api.frontegg.com/auth/vendor` (per D-06, hardcoded base URL)
- JSON body: `{"clientId": FRONTEGG_CLIENT_ID, "secret": FRONTEGG_SECRET_KEY}`
- Headers: `{"Content-Type": "application/json"}`
- Use `requests.post()` directly (not api_request_with_retry -- this is auth, same as ping pattern)
- On 200: extract token via `data.get("token") or data.get("accessToken")`
- Extract `expiresIn` (default 3600), set `_token_expiry = time.time() + expires_in - 60`
- On failure: `logging.error(f"Failed to get Frontegg access token: {response.text}")`, return None

**3. Fetch functions -- all use `api_request_with_retry("get", url_with_params, headers)`:**

CRITICAL: `api_request_with_retry` does NOT support `params=` kwarg. Append query params to URL string directly.

`fetch_frontegg_tenants()`:
- Base URL: `https://api.frontegg.com/tenants/resources/tenants/v2`
- Pagination: record-count offset (`offset += limit`), `_limit=50`, `_offset={offset}`
- URL format: `f"{base_url}?_offset={offset}&_limit={limit}"`
- Response: `response.json()` may be `{"items": [...]}` or a bare list. Handle both: `data.get("items", data) if isinstance(data, dict) else data`
- Break when `len(items) < limit` or `offset > 10000`
- Log: `logging.info(f"Fetched {len(all_tenants)} tenants from Frontegg")`

`fetch_frontegg_permissions()`:
- Base URL: `https://api.frontegg.com/identity/resources/permissions/v1`
- Same record-count offset pagination as tenants (`offset += limit`, `_limit=50`)
- Same response handling as tenants

`fetch_frontegg_roles()`:
- Base URL: `https://api.frontegg.com/identity/resources/roles/v1`
- Same record-count offset pagination as tenants (`offset += limit`, `_limit=50`)
- Same response handling as tenants

`fetch_frontegg_users()`:
- Base URL: `https://api.frontegg.com/identity/resources/users/v1`
- DIFFERENT pagination: page-number offset. `_offset` is a page number (0, 1, 2...), NOT record count.
- `_limit=200` (max for users endpoint), `_includeSubTenants=true`
- URL: `f"{base_url}?_limit={limit}&_offset={page}&_includeSubTenants=true"`
- Response: `{"items": [...], "_metadata": {"totalItems": N, "totalPages": N}}`
- Extract `items = data.get("items", [])`, `total_pages = data.get("_metadata", {}).get("totalPages", 1)`
- Break when `len(items) == 0` or `page >= total_pages - 1`
- Increment: `page += 1` (NOT `page += limit`)

**4. Write functions:**

`write_tenants(tenants, dry_run, verbose)`:
- For each tenant:
  - `tenant_id = tenant.get("tenantId") or tenant.get("id")` (per Pitfall 6 -- field name inconsistency)

  - Except: `logging.error(f"Failed to create tenant {name}: {e}")`, continue (don't fail entire migration)
- Log summary: `print(f"Tenants: {created_count} created, {failed_count} failed")`

`write_permissions(permissions, dry_run, verbose)`:
- Uses module-level `_permission_id_to_name` dict
- For each permission:
  - `perm_name = permission.get("key") or permission.get("name", "")`
  - `perm_desc = permission.get("description") or permission.get("name", "")`
  - `perm_id = permission.get("id", "")`
  - Build map entry: `_permission_id_to_name[perm_id] = perm_name`
  - If dry_run: print and continue
  - Try: `descope_client.mgmt.permission.create(name=perm_name, description=perm_desc)`
  - Except: log error, continue
- IMPORTANT: Always populate `_permission_id_to_name` even in dry_run mode (needed for role resolution)

`write_roles(roles, dry_run, verbose)`:
- Uses module-level `_role_id_to_name` and `_permission_id_to_name` dicts

  - Resolve permissions: iterate `role.get("permissions", [])`, for each perm_ref look up `_permission_id_to_name.get(perm_ref)`. If not found, log warning: `logging.warning(f"Permission ID {perm_ref} not found in map for role {role_name}")`. Collect resolved names into `permission_names` list.
  - Build map: `_role_id_to_name[role_id] = role_name`

  - Try: `descope_client.mgmt.role.create(name=role_name, description=role_desc, permission_names=permission_names, tenant_id=tenant_id)`

**5. Top-level orchestrator `migrate_frontegg(dry_run, verbose)` -- per D-08:**
```python
def migrate_frontegg(dry_run, verbose):
    token = get_frontegg_access_token()
    if not token:
        logging.error("Failed to obtain Frontegg access token. Exiting.")
        print("ERROR: Failed to obtain Frontegg access token. Check credentials.")
        return

    print("Starting Frontegg to Descope migration...")
    if dry_run:
        print("[DRY RUN MODE] No changes will be written to Descope.")

    # 1. Tenants (per D-02: tenants first)
    tenants = fetch_frontegg_tenants()
    print(f"Fetched {len(tenants)} tenants from Frontegg")
    write_tenants(tenants, dry_run, verbose)

    # 2. Permissions
    permissions = fetch_frontegg_permissions()
    print(f"Fetched {len(permissions)} permissions from Frontegg")
    write_permissions(permissions, dry_run, verbose)

    # 3. Roles (after permissions -- needs _permission_id_to_name map)
    roles = fetch_frontegg_roles()
    print(f"Fetched {len(roles)} roles from Frontegg")
    write_roles(roles, dry_run, verbose)

    # 4. Users (after roles -- needs _role_id_to_name map; per D-02)
    users = fetch_frontegg_users()
    print(f"Fetched {len(users)} users from Frontegg")
    write_users(users, dry_run, verbose)

    print("Frontegg migration complete.")
```
